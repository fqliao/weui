## 功能验收

- 首次实时运行：不读取旧缓存，验证通过后发布一级规划 / 定位缓存及二级静态操作与验证基线。
- 二级运行：真实操作浏览器，当前页面与基线一致时零模型调用，仍保存本次截图和断言结果。
- 一级运行：跳过二级；定位缓存命中，原预期由实时视觉断言验证；更新二级缓存。
- XPath 失效：仅破坏验证网站的加密定位缓存，确认自动调用模型重新定位，验证通过后重建缓存。
- 页面布局改变：回退一级，验证通过后更新二级；再次回放恢复零模型调用。
- 故意返回错误商品：判定 FAIL，真实查询请求仅发送一次，未覆盖上一份通过基线。
- Canvas 页面、单个 aiAct 中进入并离开 Canvas、人工设置始终实时：使用实时推理，不发布缓存。
- 用例版本变更：原缓存不再显示为当前版本可用。
- 相同指令出现在不同步骤：使用独立的 SDK 缓存消费状态，混合 L2 / L1 不会错取另一步的定位。
- 开放 Shadow DOM：不会把宿主元素误录为内部输入框的静态目标。
- 多动作静态脚本执行一部分后页面不匹配：停止继续回放，不重复已完成的写操作。
