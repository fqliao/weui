# 网站接入与测试指南 · v0.2

## 1. 添加网站

打开工作台 http://localhost:3100，进入“网站管理 → 添加网站”。

| 字段 | 示例 | 说明 |
|---|---|---|
| 网站名称 | 订单系统 · 测试环境 | 供任务选择 |
| 网站地址 | https://test.example.com | 执行服务器必须能够访问 |
| 默认测试浏览器 | Google Chrome | 可选择 Chrome（默认）、Edge、Firefox |
| 额外允许的域名 | https://sso.example.com | 每行一个完整地址；包含登录、API、CDN 依赖 |

主站 origin 自动加入范围。其他域名请求会被阻断。支持内网 HTTP(S)，URL 不能携带密码，不能使用本机工作台 / API / 基础服务地址。网站配置发生变化后，旧任务需要重新创建。

“用例库”的运行栏可为本次执行选择浏览器，不必修改已保存的用例；网站探索沿用网站默认浏览器。运行报告的“运行配置、版本与模型费用”显示选择，一键回归继续使用该浏览器。Chrome、Edge 使用执行服务器已安装的浏览器；Firefox 使用 `pnpm exec playwright install firefox` 安装的专用构建。浏览器缺失会明确报错，不会静默换成其他浏览器。

## 2. 配置登录身份

在“登录会话”选择网站，每个角色建立一条配置。平台登录账号和被测网站账号相互独立。

**账号密码**：填写登录路径、账号密码、账号输入框描述、密码输入框描述、登录操作和成功条件。首次通过 Midscene 定位操作，通过后优先复用静态记录。

成功条件支持“自然语言判断”和“结构化验证”。结构化条件可以组合 URL、文本、可见/隐藏、控件状态、非空及页面位置，由 Playwright 等待并验证。自然语言首次验证通过后会自动尝试沉淀完整静态条件；不支持的复杂语义继续实时验证，并在报告说明原因。凭据始终从本次配置注入，零 Token 回放并不等于复用旧登录状态或旧通过结果。

**导入会话**：对 SSO、验证码或 MFA，先在授权测试浏览器中完成人工登录，再导入 Cookie / localStorage。此版本不提供自动验证码或浏览器人工接管。支持格式：

```json
{
  "cookies": [{"name":"session","value":"测试会话值","domain":"test.example.com","path":"/","httpOnly":true,"secure":true,"sameSite":"Lax"}],
  "origins": [{"origin":"https://test.example.com","localStorage":[{"name":"token","value":"测试令牌"}]}]
}
```

Cookie domain 必须是允许列表中的精确主机，不接受宽泛父域。过期 Cookie 会被拒绝。导入会话的验证地址应填写登录后的页面，例如 `/dashboard`，成功条件应匹配该页面。

凭证加密保存；编辑时账号、密码或 JSON 留空可保留原值。列表和报告只返回名称、版本和是否已配置秘密内容。修改、停用或到期会阻止旧任务继续使用会话。保存后可以“生成登录验证计划”，确认后查看结果。生成的验证用例会检查登录完成时的页面；正常业务用例则会继续打开指定入口。

## 3. 编辑功能和用例

用例库（含原“运行测试”入口）的统一列表默认每页 10 条，可切换为 20 / 50 条。支持名称搜索、上一页 / 下一页，跨页保留选择，单次执行仍最多 12 条。当前为前端分页，服务端仍读取网站功能及用例目录。

列表提供“全选本页”复选框（再次点击取消本页选择）、“全选筛选结果”和“清空选择”。全选筛选结果覆盖当前网站、功能、搜索及停用条件下的所有页；切换筛选会保留已选项，并显示筛选范围外的已选数量。选择数量不受 12 条限制；超过 12 条或包含停用项时，运行按钮不可用并说明原因，不会只执行其中一部分。

每行“删除”用于单条删除，“删除所选”用于批量删除。确认窗口列出本次所有用例的名称、功能和版本，包含跨页选择，取消不会修改数据。服务端校验项目权限、网站范围及版本；任何一条已修改或已删除，整批均不提交，刷新列表后重新确认。停用用例也可以删除。

删除只从用例库移除条目，保留删除审计和历史快照；已创建的任务、运行及报告不会被改写，也不会停止正在进行的测试。旧报告仍可按原快照回归；新建测试不能选择已删除用例。此操作不会清理被测网站中的业务数据。

点击“新建用例”或“编辑校准”打开右侧抽屉，列表保留在左侧；保存后关闭抽屉并保留当前页与选择。关闭按钮、Esc 或点击遮罩均可关闭；存在未保存修改时先选择继续编辑或放弃，保存请求进行中不能关闭。


功能保存业务规则与范围，每条用例选择一个登录身份。多个角色可分别创建用例。用例结束后销毁会话，不会复用另一条用例的 Cookie。

| 项目 | 示例 |
|---|---|
| 功能 | 商品搜索 |
| 用例 | 搜索红茶 |
| 入口 | /products |
| 身份 | 访客或已配置的普通用户 |
| 前提 | 商品目录已经存在红茶 |
| 操作 1 | 类型“输入”，描述“商品搜索框”，值“红茶” |
| 操作 2 | 类型“点击”，描述“搜索按钮” |
| 预期 | 搜索结果包含红茶商品 |
| 清理 | 查询可留空；创建数据的流程应配置对应清理 |

“自然语言操作”支持多步流程，例如“搜索红茶，打开第一个商品详情”。明确步骤可选择点击、输入/清空、下拉选择、勾选/取消/单选、悬停、按键和等待。步骤可新增、删除、上下移动。每项预期可选自然语言判断或结构化验证，至少保留一项。不执行用户提供的任意 JavaScript。

要优先静态执行，在步骤中勾选「指定控件定位」，填写字段标签、角色与名称、可见文本、占位提示、测试 ID 或高级 CSS。等待步骤可改用结构化条件；预期结果可检查文本、值、可见性、勾选状态、可操作状态、元素数量和 URL，也可组合多个 AND / OR 条件。明确配置完成后，选择二级优先可从第一次就直接静态执行；定位变化时逐级回退，明确预期失败时保留失败结果。

「测试数据参数」定义用例级数据，例如 `name = 自动测试-{{runId}}`，然后在输入值和预期值中同时使用 `{{data.name}}`，每次运行使用相同的本次数据。缺少参数会在保存及执行前报错。参数可保存到用例，当前没有数据表批量运行或单次覆盖参数界面。不要将真实凭据放入普通测试参数。

用例库展开「执行能力」可看到每一步是否具备静态条件、是否已有二级记录、是否首次需要 AI 定位或仍需 AI 判断。这里是运行前的能力预览；报告显示本次实际使用的执行层。登录准备及清理也会影响完整用例的 Token 消耗。支持范围与限制见 [分层执行缓存](分层执行缓存.md)。

所有预期都会在操作步骤完成后的同一个页面上检查。成功登录与错误密码登录应拆成两条用例。测试登录表单本身时，身份选“访客”，入口填实际登录地址（Hash 路由例如 `/#/auth/login`）；需要自动使用已保存账号验证登录时，优先在“登录会话”点击“生成登录验证计划”。普通业务用例则选择已保存身份，登录通过后再执行业务步骤。

前置条件是业务背景，不自动创建数据；需要自动准备的操作应写入步骤。操作、输入值和预期支持 `{{runId}}`、`{{caseId}}`：例如创建“自动测试 {{runId}}”，清理时定位相同标题，避免影响其他数据。

## 4. 选择用例直接测试

每次可选择「二级缓存优先 / 一级缓存优先 / 实时推理」，用例行显示已生成的缓存级别。对于 Canvas、iframe 等特殊页面，或编辑中设为「始终实时推理」的用例，执行器跳过缓存。具体命中、回退、重建规则见 [分层执行缓存](分层执行缓存.md)。

主流程为 **探索生成草稿 → 人工校准发布 → 选择用例测试 → 查看过程与结果 → 一键回归**。

- 点击侧栏“选择用例测试”或“用例库”，进入同一列表。选择网站后可以跨功能、跨页勾选，点击“运行所选”，每次最多 12 条。
- 功能只是筛选条件，不再需要逐个切换功能后执行；单条仍可点击“立即测试”。浏览器选择合并在运行栏。
- 探索详情以草稿列表展示，点击“审核校准”打开右侧抽屉，先保存修改、再审核发布。发布后点击“去用例库测试”，自动选中本次发布的用例。
- 默认使用所选用例保存的登录身份、步骤、预期、参数和清理配置。执行前自动冻结网站、用例、功能、会话与知识版本；直跑不调用规划模型，浏览器操作和断言按二级静态、一级缓存、实时推理策略执行。
- 用例库“更多 → 按测试目标规划”保留知识 / Skill / Agent 规划；未执行的计划在测试记录的次级标签中查看。内置审批样例也收在“更多”中。

默认整次运行共享 10 分钟、100 个动作、60 次模型调用、150000 tokens；目标规划模式可调整动作上限。自然语言步骤可能涉及多次定位，实际消耗高于步骤条数。规划和视觉模型费用按返回用量及保存的单价估算；缓存明细缺失时按未命中计算，不能理解为供应商账单或严格费用硬限额。

## 报告下载、费用与反馈

- 普通网站用例的步骤、断言截图逐项保留，最终提供一份 Midscene HTML 报告。旧运行中的阶段报告仍可在「阶段报告与历史附件」展开下载，按断言编号或阶段区分。
- 管理员进入「空间设置 → 模型价格」查看和编辑当前规划、视觉模型的单价。币种为人民币（元），单位为百万 Token；当前内置 DeepSeek Flash 的官方人民币价格核验快照，可点击来源核对。高峰按北京时间工作日 09:00–12:00、14:00–18:00，其余按空闲单价。价格未开启定时同步，后续变价应由管理员核对并更新。
- 新运行记录模型、Token 用量、人民币价格和费用估算，显示 ¥ 金额，修改设置不会改写旧记录。此前美元明细按 Token 及当前人民币单价给出参考估算，原始美元记录保留。旧运行没有记录视觉模型名称时，只能假设使用当前视觉模型提供「历史费用参考」；混合模型且无法拆分时保持未知。回归复用计划，不重复计入之前的规划费用。
- 提交反馈后，在运行页下方查看「本次运行的反馈」，或从左侧「反馈记录」集中查看、按类型筛选和分页，并跳转原运行。当前工作空间成员均可阅读，其他工作空间不可访问。
- 反馈是平台内的改进记录，不会自动发邮件、创建外部工单、改写测试预期或结论。需要校准用例时，由测试人员在用例库编辑并保存新版本。

运行报告的“一键回归”使用原计划快照。**要验证修改后的用例，请从用例库重新选择。** 网站或登录配置发生变化时，旧快照会被拒绝，需要创建新的测试。服务端对重复请求去重，并检查同网站同用例的前次执行是否仍在进行、存在未知结果或清理失败，避免换入口绕过保护。

## 5. 查看结果

测试记录每行代表一次正式运行，同一用例的多次回归分别保留；探索任务、Skill 调试不混入正式测试记录。支持网站、名称、进行中 / 需要关注 / 全部通过筛选和服务端分页。默认隐藏已停用网站，勾选后可查历史。

报告只用一处用例切换来联动截图、步骤和预期 / 实际详情；时间线、运行配置与模型费用按需展开。

运行中可查看当前用例、正在执行的动作、所选浏览器的真实画面（约 2 秒刷新）和逐项验证状态。登录凭据输入阶段显示“正在准备登录身份”，不发送登录截图。连接暂时中断会提示画面更新失败；重新进入页面会恢复读取后台状态。

运行后可切换用例，点击“步骤 1 / 验证 1 / 结束画面”等关键截图回看，并核对每项预期与实际观察。这里提供实时截图与关键帧回看，不是视频录制或浏览器人工接管。实时画面只保留最新一帧，24 小时过期；步骤与验证证据按既有证据保留策略管理。

运行结束后，打开的报告仍会定期更新核对、清理和重跑状态；回到浏览器窗口时立即刷新，也可点击右上角“刷新状态”。状态查询暂时失败时保留已加载的结果并自动重试。解除重跑限制不会把原来的失败结果改成通过，修正配置后应查看新一次运行的结果。


| 结果 | 含义 |
|---|---|
| PASS | 配置的页面断言成立，且保存了证据 |
| FAIL | 页面断言不成立 |
| BLOCKED | 登录、配置、范围或环境阻断 |
| INCONCLUSIVE | 操作中断或证据不足，无法可靠下结论 |
| SKIPPED | 未执行 |

页面断言不等于后台事务验真。确认订单持久化、库存扣减和账务正确，需要额外业务查询。审批样例已有独立业务断言，通用网站默认只有 UI 证据。

报告提供断言解释、截图、事件和 Midscene HTML 下载。报告包含被测页面截图，按测试数据权限保管。登录阶段使用单独的 Agent，口令不进入公开业务报告。

浏览器和隔离会话会自动回收，业务数据按用例的清理步骤处理。未尝试业务 UI 写动作时显示“无需清理”，不会额外执行删除操作；已执行操作但清理为空时显示“未配置清理步骤”。完整事件能证明未尝试业务写动作的历史误判可自动解除重跑限制，未知写结果或清理失败仍需核对被测系统。重跑使用原计划，修改用例后应新建测试任务。

还没有测试用例时，可先使用 [网站探索与用例沉淀](网站探索与用例沉淀.md)：提供网站和需求，让 Agent 观察页面并生成草稿，人工校准、审核发布后再正式测试。

## 架构与模型

TypeScript / Next.js → Fastify → Deep Agents → BullMQ Worker → Midscene PlaywrightAgent → Playwright → Chrome / Edge / Firefox。Playwright 管理浏览器、会话和截图，UI 操作和页面断言统一使用 Midscene。

本机模型为 `deepseek-flash`，`MIDSCENE_MODEL_FAMILY=deepseek`，复用本机已有 DeepSeek 凭证。自然语言步骤使用 `deepThink: true`，通过独立视觉定位执行每个动作。


## 重复运行提示的含义

“上次操作中断，尚不能确定是否产生了业务影响”表示此前有未确认结果的 UI 动作，不是浏览器缓存问题。页面会保留提示，提供“查看上次运行”及用例库中的“编辑此用例”，可展开具体原因。保留历史原始结论，关闭浏览器不等于确认业务结果。

运行被旧结果拦截时，可先点击“取消选择此用例”测试其他项。要恢复该用例，先修正配置，再点击“核对上次结果”，查看被测网站的实际状态，选择“未产生需要清理的业务数据”或“已核对并清理产生的业务数据”，填写核对说明并确认。保存后重新点击“运行所选”，按最新保存的用例创建任务。编辑用例本身不会自动核对旧运行。

核对记录绑定原运行、具体用例及执行记录指纹，保存核对人、时间、说明，可在旧运行报告的“人工核对记录”查看。原测试结果、截图和清理状态保持不变；核对一条不会释放同批次其他未知项，也不适用于后续的新运行。此入口用于已结束且浏览器已回收的通用网站运行；正在执行、清理失败和浏览器回收异常仍需处理实际异常。保存核对只记录确认，不会自动清理被测网站数据。

核对说明填写非空内容即可，不要求至少 5 字，最多 1000 字。点击保存时，缺少说明或未勾选确认会在对应字段旁提示并定位；仅在保存请求处理中暂时禁用按钮。

直跑只检查所选用例的前次结果，同批次另一条异常不会连带阻止尚未执行或仅认证被中断的用例。整批一键回归仍检查整个批次；清理失败、浏览器回收失败或仍在执行仍受保护。混合选择中只要有异常用例，就不会启动该批次。

已选登录身份会在正式步骤前使用加密保存的凭据自动登录。不要随后再写含糊的“输入普通用户名和密码”，否则执行器无法从步骤取得明确输入。仅验证自动登录时，选“使用登录完成时的页面”并保持操作步骤为空；正向登录与错误密码提示应拆成两条用例。Agent 上下文明确禁止猜测未提供的账号密码。

对于已配置登录身份、只有一条自然语言登录步骤的用例，编辑抽屉提供“改为仅验证已保存身份”：移除重复步骤并使用登录完成时的页面，原预期结果保持不变，检查后保存即可。
