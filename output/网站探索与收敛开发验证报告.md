# 网站探索与收敛开发验证报告

日期：2026-09-14。核心为 TypeScript，规划采用 Deep Agents，UI 操作为 Midscene，使用 Google Chrome。已更新本机 Web 平台。

## 本次交付

- 独立探索入口：网站地址/登录身份、需求粘贴与 TXT/Markdown 导入、领域知识版本、页面预算。
- 主链路、边界、发散三阶段。后两阶段必须引用同网站上一阶段已发布用例的正式验证结果，服务端阻止跳级与未知结果推进。
- 受控导航与页面观察，保存截图、需求引用、规则引用、待确认问题和未覆盖项。没有新用例时允许空结果。
- 双层收敛：实际动作序列回注上下文、重复动作拦截、相似页面去重、候选路径新颖度排序。
- 独立草稿库、人工编辑、审核意见、驳回/发布、版本冲突与重复发布保护；已发布用例进入现有正式测试流程。
- 浏览器回收与业务清理分别展示。无实际业务 UI 写动作的执行不启动业务清理；符合完整事件证明的历史误判可重新执行，原结论不改写。

## 使用边界

探索观察与导航阶段不直接填写、提交业务表单。图中“走通主链路、留空填错并验证”的实际业务操作，放在人工审核后的正式用例执行；下一阶段必须引用该执行结果。当前不支持探索中的自由按钮/弹窗操作、Word/PDF 自动解析、大规模全站覆盖或后台事务独立验真。

这是独立验收网站的功能验证，不代表用户网站的全部业务需求已验证。完整说明见 [网站探索与用例沉淀](../docs/网站探索与用例沉淀.md)。
